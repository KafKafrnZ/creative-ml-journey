# creative-ml-journey

I'm chasing a rare hybrid: someone who can ship both polished creative-developer work and real AI/ML engineering, not just dabble in each. Most people pick one lane or stay a tutorial-collector in both; I'd rather spend the next 18-30 months building shipped, provable depth in each track and then combine them into hybrid creative-AI products, because that combination is what gets you into rooms most single-specialty engineers never reach. This repo is the public, dated proof that the work actually happened — not notes I kept to myself, not courses I "finished," but code, artifacts, and a changelog that show the track record.
